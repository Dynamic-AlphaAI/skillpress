# Skill Press

Agent skills, typeset and bound as books you can page through and then install. The design takes its cues from [stripe.press](https://stripe.press).

## Source libraries

The catalogue contains **971 editions from 61 GitHub repositories**. Its 22 topic collections share 11 rooms and 186 occupied shelves. The main hall holds 736 editions across 155 shelves in 32 wall cases. Low cases let you browse from the floor, and taller cases have rolling ladders. Choose a topic first, then narrow by author or AI platform. Book notes show the publisher’s intended host or documented compatibility. [Collection guide and source review](docs/collections.md)

- **Ranking:** install counts from the [skills.sh](https://skills.sh) leaderboard. Skills it doesn't list yet appear at the end of their topic.
- Books sit together by primary task across the catalogue, shelf, and 3D room. For example, **Testing & Code Review** includes browser testing, debugging, and reviewing changes. The **Author** filter narrows any topic to a particular author. Within each topic, books follow their install rank.
- **Books:** each one is the skill's `SKILL.md`. Downloads include the skill folder and license. Reading editions package the original instructions with selected guides and link to the publisher for runtime setup.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

## Add a library

1. Add an entry to `sources.json`: the repository, canonical skill directory, author, and reviewed commit in `revision`. Use `additionalPaths` for separate published plugins. Use `skillPaths` for individual reviewed skill folders at a pinned commit. Only include each canonical directory once.
2. Run `npm run import`.
3. Run `npm test`, `npm run lint`, and `npm run build`. Run the browser checks against a production preview as described in the [collection guide](docs/collections.md).

To give books their own titles and covers, add entries in `src/lib/designs.ts`. Series entries supply their titles and subtitles there. The edition ID and subject select a stable jacket in `src/lib/jacketDesign.ts`. Topic names and shelf order live in `src/lib/categories.ts`. File a skill by its primary task in `src/lib/classifyTopic.ts`, using the upstream repo and folder to identify the edition. For curated folders, an explicit entry in the source’s `topics` map takes priority. An unreviewed import with a single clear topic match uses its own name and description. Ambiguous imports appear under **Awaiting Classification**.

## Keeping it up to date

A GitHub Action (`.github/workflows/update-skills.yml`) runs `npm run import` every day at 06:17 UTC. If anything changed and the site still builds, it commits to `main`, and Vercel deploys that commit. You can also run it from the Actions tab.

`npm run import` reads the reviewed revisions of the pinned collections, follows the default branches of the original three, and refreshes install counts. Change a pinned revision after reviewing its upstream diff. The importer requires YAML skill metadata and instructions, rejects symlinks, and packages tracked files with an identified license. Within one credited author’s catalog, matching folders, skill names, or instruction bodies share one edition. Different authors can publish the same skill. Each author’s edition has a permanent reader link and download, and its ZIP retains the upstream install folder name. A successful import replaces two folders:

- `content/`: the text each book is typeset from, plus `catalog.json`.
- `public/downloads/`: `<skill>.zip`, `<skill>/SKILL.md`, `<library>-skills.zip`, and `skillpress-all.zip`. Zips are byte-identical when nothing changed, so the daily job doesn't keep re-committing them.

## Getting a skill

**Get skill** (in the footer, the reader, or by pressing `g`) opens a panel with:

- **Download .zip**: the whole skill folder, ready for a skills directory or for Claude.ai's *Customize → Skills → Upload a skill*.
- **SKILL.md only**: just the instructions.
- **Agent prompt**: paste it into Claude Code, Codex, Cursor, or any agent that runs commands, and it installs the skill and reports back what it does.
- **skills CLI** installs from the edition’s pinned GitHub directory using the name declared in its frontmatter.
- **Claude Code**: the plugin command published by each library.
- **Claude.ai** offers toggle or upload steps for Claude editions. Supported ChatGPT editions link to their plugin or workspace setup. DeepSeek editions include Harness discovery instructions, and xAI’s internal bridge guide links to its upstream plugin.

## Using it

Choose **Search** in the header to look up skills by keyword, title, publisher, topic, or words in the instructions. Results update as you type. Choose a topic above the catalogue or use the author and platform filters to narrow them, then select a result to read the book. A link such as [a search for PDF extraction](https://skillpress.xyz/?q=pdf+extraction) restores the query. The full-text index is built from the same checked-in editions as the reader and loads when Search opens.

Enter the Main Reading Hall to browse about three quarters of the collection, arranged by topic in cases along the outside walls. Signed doorways on both sides open into Arts & Letters, Engineering Workshop, Research & Planning, Operations Room, Business & Commerce, Design Gallery, AI & Model Lab, Data Archive, Mobile Studio, and Infrastructure Room. Drag the joystick up or down to walk and left or right to turn. Tap the small buttons underneath for one sideways step, or hold to keep stepping. You can also drag the scene to look up and down, scroll to walk, or use the keyboard. The expand button at the entrance or inside the room opens a near-full-screen walkthrough. Closing the expanded view returns you to the same spot. Each matching edition has one physical place. The room, shelf, and volume pickers also work by keyboard and without WebGL. Small filtered collections fit entirely in the hall.

Browse the first three shelf rows from the floor. Bookcases with a fourth row or higher have a ladder, and neighboring tall cases share a rail. Select a ladder or press **E** to board the nearest one in that room. Push the joystick up or down, scroll, or use **W/S** to climb. Use the sideways buttons or **A/D** to roll along the bookcase, and select a book to read. Press **E** or choose **Step off ladder** to return to the floor. Choosing an **Upper shelf** in the shelf picker takes you straight to that row.

The sound control in the masthead and reader remembers your preference on this device. In a book’s details, drag the cover or press **Turn book** to inspect its boards, spine, and printed back.

**Shelf and Featured controls**

| | |
|---|---|
| `←` `→` / scroll / drag | browse the shelf |
| click a spine | pull it out |

Direct links include `/?walk` for the walkthrough and `/?view=shelf` for the original shelf, alongside `/?category=writing-documents`, `/?author=jesse-vincent`, `/?book=pdf&read&page=4`, `/?book=cro&install`, `/?view=featured`. With no book chosen, the shelf opens on its middle book.

## How it's built

- `sources.json`: the libraries on the shelf.
- `scripts/import-skills.mjs`: pulls the skills, ranks them, and builds the zips (with `fflate`, so no system `zip` is needed).
- `src/lib/library.ts`: parses frontmatter and renders the markdown on the server. Raw HTML is escaped, relative links point at GitHub, and heading ids feed the contents pages.
- `src/lib/install.ts`: the install methods. The commands match each library's README and skills.sh.
- `src/components/Shelf.tsx` and `Book3D.tsx`: the shelf. Each book is a CSS 3D box, and its thickness follows the word count.
- `src/components/EditionJacket.tsx` prints the same jacket in the catalog, reader, and walking room. `JacketIllustration.tsx` draws the subject illustrations. `CoverArt.tsx` holds the individually art-directed original covers.
- `src/components/useUrlState.ts`: the URL is the single source of truth for what's on screen, and the page itself is fully static.
- `src/components/ReadingRoom.tsx` and `WalkingRoom.tsx` present the gallery and its keyboard- and touch-accessible shelf controls. The Three.js scene in `roomScene.ts` loads on entry, renders on demand, and generates bookcases from the filtered catalogue.
- `src/components/sound.ts` synthesizes footsteps, book handling, and paper sounds locally with Web Audio.
- `src/app/editions/[id]/route.ts` builds a static edition for each book. The reader fetches the selected edition when it opens.
- `src/components/Reader.tsx`: the book itself. Text flows through CSS columns at a fixed page size, so pagination is the same at every window size. The whole book is then scaled to fit. Pages turn with the Web Animations API, and the turning leaf stays mounted so long books turn smoothly.
- `src/components/Details.tsx`: details, downloads, and copy-ready install instructions.
